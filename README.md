# The Pleasure Dispatch by FLRSGLOBAL — Outlook MVP

A first working concept for a custom Outlook compose experience. It provides a branded editor for the six recurring sections of The Pleasure Dispatch and inserts a finished HTML newsletter into a new Outlook message.

## MVP flow
1. Host this web app over HTTPS.
2. Sideload `manifest.xml` into Outlook.
3. Open a new message.
4. Click **The Pleasure Dispatch**.
5. Fill in the editorial sections.
6. Preview or **Build in Outlook**.

## Current sections
01 A Note on Pleasure
02 The Image
03 The Encounter
04 Pleasure, Currently
05 From FLRSGLOBAL
06 A Question
